# 实现计划

1. 建立 Astro、TypeScript、Vitest 与静态构建基础。
2. 定义并测试站点、下载、采集、资源与发布配置 Schema。
3. 定义发布文章 Content Collection 和示例文章。
4. 实现首页、归档、文章、下载中心、来源页和全局布局。
5. 实现 Markdown、通用 HTML、微信公众号 HTML 导出。
6. 实现 Chrome 发布检测和外部图片仓库同步脚本。
7. 增加 RSS、JSON Feed、Pagefind 搜索和站点地图。
8. 增加 GitHub Pages、Cloudflare Pages 和定时检测工作流。
9. 补充开源仓库文档、配置指南和安全说明。
10. 运行测试、类型检查、生产构建和浏览器响应式验证。
