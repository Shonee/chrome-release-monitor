# Release Radar for Chrome 设计文档

## 问题与目标

项目需要定时发现 Chrome 稳定版更新，将官方信息沉淀为可编辑 Markdown，生成适合阅读与跨平台发布的静态页面，同时提供来源透明、可配置的浏览器下载入口。

## 方案选择

- Astro 静态站点：内容集合管理文章，适合 GitHub Pages 和 Cloudflare Pages 共用同一构建产物。
- 配置优先：品牌、导航、链接、下载源、采集源、资源仓库和发布格式均存放在 `config/*.json`。
- Markdown 为事实来源：页面、RSS、JSON Feed 和三种导出格式都从同一篇 Markdown 生成。
- GitHub Actions 定时检测：检测到新里程碑或补丁后更新文章草稿并创建自动化分支。
- 外部资源仓库：功能图片只经过内存校验后上传到独立 GitHub 仓库，不写入主仓库。

## 责任边界

- 采集脚本确认版本与官方来源，不自动声称未核验的功能或安全数据。
- 社区下载入口不标记为 Google 官方镜像。
- GitHub Pages 与 Cloudflare Pages 仅托管静态产物，不引入平台专属运行时。
- 默认拒绝 HTTP 下载源、非允许域名图片和超限资源。

## 成功标准

- 配置修改后无需改组件即可更新站点内容。
- `npm run build` 同时生成站点、搜索索引和发布导出文件。
- 采集、导出、URL 安全与资源路径具备自动测试。
- 桌面与移动端无横向溢出，主要流程可用。
