Web Platform

滚动触发动画

Chrome 152 增加滚动触发动画能力，让动画只在滚动时间线进入指定范围后启动。它适合用于进入视口后的内容呈现，而不必持续运行整条滚动动画。

CSS
.notice {
  animation: reveal 450ms ease both;
  animation-trigger: view();
}

@keyframes reveal {
  from { opacity: 0; transform: translateY(12px); }
  to   { opacity: 1; transform: translateY(0); }
}

使用建议

  1. 先保留无动画时的可读状态，避免内容依赖动画才可见。
  2. 通过特性检测决定是否启用增强效果。
  3. 为开启“减少动态效果”的用户关闭非必要动画。
Navigation

识别历史记录导航

`Request.isHistoryNavigation` 可以判断导航是否由浏览器前进或后退触发。服务端或 Service Worker 可据此采用不同缓存策略，但不应把它作为安全判断依据。
